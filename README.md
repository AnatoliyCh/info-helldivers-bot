# info-helldivers-bot

Отправляет данные главного приказа в чат

### Используется

- [bun](https://bun.com)
- [gramio](https://gramio.dev)
- [puppeteer](https://www.npmjs.com/package/puppeteer)

### Развертывание

1. установить [bun](https://bun.com)
2. установить локальный браузер (и его зависимости) для работы [puppeteer](https://www.npmjs.com/package/puppeteer)
    - `bunx puppeteer browsers install chrome`
3. запуск `bun index.js`
